### 🎓 from the classroom

- **🧀 [BrieHosting](https://github.com/YliasR/briehost-api)** — a cheesy web-hosting platform (team SKIL2 project). Upload a zip or point it at a public Git repo, and it scans, provisions, and spins your site up in an isolated container on its own subdomain. Proxmox + Supabase + FastAPI + Ansible + Caddy, with ClamAV/YARA malware scanning, a JWT-gated control layer, and real Stripe + crypto billing.
